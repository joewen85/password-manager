# Flutter 历史数据迁移兼容回归清单

更新时间：2026-07-28

## 1. 目标与支持边界

本清单验证旧 Flutter App 产生的历史保险库可以安全迁移到当前 HarmonyOS 客户端：

1. HarmonyOS 能读取并解密历史数据。
2. HarmonyOS 首次保存或同步后，历史条目、标签和秘密字段不损坏。
3. 迁移过程不在日志、截图或测试记录中泄露明文敏感信息。
4. 创建字段关联后，关联模板、稳定 ID 和引用值能由当前维护客户端继续保留。

旧 Flutter App 已从仓库移除，不属于当前维护的写同步客户端，也不支持 `valueType`、`targetCategory`、`templateFieldId` 和完整 `customFields` 契约。因此本清单不是双向写回兼容承诺：

- 可验证“旧 Flutter 历史数据 -> HarmonyOS”的迁移。
- 创建字段关联后，不得再使用旧 Flutter 版本写入同一远端保险库。
- 降级到旧 Flutter、HarmonyOS 写回后再由旧 Flutter 重写、以及旧 Flutter 双向同步均不受支持。

## 2. 前置条件

- 使用隔离的测试远端或远端对象副本，不直接操作唯一生产副本。
- 已准备旧 Flutter 产生的历史密文数据，并能记录其条目数、标签数和抽样内容。
- HarmonyOS 使用当前维护版本，并已通过 `harmony_preflight.sh` 与 unsigned HAP 构建。
- 真机验证使用 signed HAP，并具备 `hdc shell hilog` 日志采集能力。

## 3. 安全备份

1. 下载远端 `vault.json` 或等价同步对象，保存为只读备份。
2. 记录备份文件名与 SHA256：

```bash
shasum -a 256 <backup-file>
```

3. 记录迁移前基线：总条目数、三类条目数、标签数、已删除条目数和三条脱敏抽样记录。
4. 后续测试仅使用备份副本或隔离远端；失败时停止同步并恢复该备份。

## 5. 日志与隐私检查

可按时间段采集 HarmonyOS 日志：

```bash
hdc shell hilog | grep -E "Vault|sync|encrypt|decrypt|CryptoArchitectureKit"
```

人工确认日志、截图和测试记录中不包含：

- 主密码、条目密码、Token、Secret、Authorization 或 Bearer 值；
- 完整远端凭据或签名 URL；
- 存储的字段关联 ID；
- 未脱敏的真实用户数据。

## 6. 阻断与恢复

出现以下任一情况即停止迁移：

1. HarmonyOS 无法解密历史数据。
2. 条目、标签、自定义字段或模板明显减少或被清空。
3. 创建关联后，当前维护客户端无法保留关联字段元数据。
4. 日志或 UI 暴露引用 ID、目标密码、Token、Secret 或备注。
5. 旧 Flutter 仍可能自动同步并覆盖远端。

恢复步骤：停止所有客户端同步，保存失败日志和远端对象，将隔离远端恢复到第 3 节备份，并记录用例 ID、设备、时间和复现步骤。
